\# futurisys-ml-api

Déploiement d'un modèle ML via API FastAPI



\#installation

git clone https://github.com/NIX3S/futurisys\_ml\_api.git

cd futurisys\_ml\_api

pip install -r requirements.txt



\# Futurisys ML API



API de déploiement d’un modèle de machine learning développée avec FastAPI.



\## Objectifs

\- Exposer un modèle de ML via une API REST

\- Mettre en place des tests automatisés

\- Déployer via un pipeline CI/CD



\## Stack

\- Python

\- FastAPI

\- Pytest

\- PostgreSQL

\- GitHub Actions
